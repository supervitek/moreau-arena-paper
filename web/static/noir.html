Moreau Noir / Track 1 / Final report

Memory changed the record. It did not produce a stable change in the decision.

Track 1 tested whether a structured memory carrier could spill into a fresh decision context. The core Terra experiment produced an informative bounded null. Five follow-up programs found no stable carrier-sensitivity channel, while also exposing where routes, output contracts, and task headroom limited what could honestly be inferred.

02

What did Noir ask?

A narrow causal question, not a model ranking.

If a model receives a structured record of an earlier world, does that record change its choice when the model is placed into a fresh, unlabeled decision fork?

Each paired fork held the task and scoring logic fixed while changing the registered carrier condition. The observable was whether the model selected the higher-task-optimal or lower-task-optimal response class.

The experiment was deliberately narrower than “does memory matter?” It tested one frozen carrier, task family, route, exposure, and fresh-context contract at a time.

03

How the evidence was protected

The engineering discipline is part of the scientific result.

1

Freeze first

Tasks, manifests, routes, schemas, scorers, gates, and terminals were bound before model execution.

2

Fresh paired contexts

Each carrier arm ran in a fresh isolated process or session to prevent conversational carryover.

3

Dual scoring

Primary and reference scoring had to agree before a response could enter the accepted core evidence.

4

Strict route identity

Requested model, canonical endpoint, provider, attempt count, and usage accounting were validated where exposed.

5

No retry or salvage

Rate limits, malformed JSON, substitutions, truncations, and wrong schemas stayed invalid exactly as observed.

6

Qualification gates

Metadata, route response, carrier readback, behavioral profile, and retest were separate earned depths.

06

Where the assay stopped

A failure can constrain the interface without answering the behavioral question.

Route qualification ≠ behavioral qualification Phase-0 failure ≠ behavioral null Single class ≠ estimated zero effect Invalid output ≠ salvageable response

No behavioral headroom

When both carrier arms and NULL controls stay in one response class, an ordinary directional contrast cannot become informative.

No-retry incompleteness

The prospective one-attempt rule preserved accounting but left MiniMax, Fable, and four Chinese routes incomplete.

Rate and route limits

DeepSeek and Kimi hit upstream rate limits; Fable substitutions made requested-target evidence invalid.

Strict output contracts

Markdown-wrapped JSON, wrong schema versions, null content, and truncation were preserved as interface failures.

Missing provenance

The accepted substrate lacked a distinct immutable counterparty-action channel, so one proposed composition could not be claimed.

Burned diagnostics

Calibration, route-health, disambiguation, and retest cells remain valid for their original purpose but cannot become fresh confirmation.

Claims this report does not make

  • All models were null or all Chinese models were insensitive.
  • Spillover is universally zero or memory cannot affect LLMs.
  • Terra and Luna are equivalent systems.
  • Moreau Noir proves deployment safety.
  • The system atlas is a leaderboard.

Track 1 remains closed

Reopening requires a new prospective scientific reason: demonstrated task headroom, a genuinely new immutable carrier channel, external replication, a scientifically motivated new route, or a new exact world/substrate. A rerun, provider repair, new model release, or desire for more data is not enough by itself.

Final disposition No held-out or main/scored follow-up justified
